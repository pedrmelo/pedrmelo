## 🚀 Projeto em Destaque — TCC

### 🪵 Avaliação da Qualidade de Dormentes Utilizando Visão Computacional e Redes Neurais Convolucionais

> Trabalho de Conclusão de Curso — Engenharia Mecatrônica, UFSJ

Desenvolvimento de um sistema automatizado para classificação e avaliação da qualidade de dormentes ferroviários de madeira, utilizando técnicas modernas de visão computacional e deep learning.

**O que o projeto faz:**
- Captura e processa imagens de dormentes para extração de características visuais
- Aplica redes neurais convolucionais (CNNs) para classificação automática de qualidade
- Gera métricas e relatórios visuais de desempenho do modelo

**Stack utilizada:**

| Tecnologia | Uso |
|---|---|
| `Python` | Linguagem principal |
| `TensorFlow / Keras` | Modelagem e treinamento da CNN |
| `OpenCV` | Processamento de imagens |
| `NumPy / Pandas` | Manipulação e análise de dados |
| `Scikit-learn` | Métricas de avaliação |
| `Matplotlib` | Visualização de resultados |
